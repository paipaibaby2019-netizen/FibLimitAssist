## 项目定位
MT5半自动EA，**交易方向、行情判断完全人工**；EA负责绘图UI、按钮交互、风险手数计算、下发`ORDER_LIMIT`限价挂单；无自动行情识别、无自动开仓。
> 每一张图表附加EA，各自独立拥有1套斐波那契；不同图表互不干扰。
> MT5重启 / EA重新附加，绘图状态丢失，属于可接受范围；**会话内（缩放、切换周期）绘图、按钮、数据保持不丢失**。

## 斐波那契结构与方向（重要）
- 上涨：低点 = **1.00起点**，高点 = **0.00终点**
- 下跌：高点 = **1.00起点**，低点 = **0.00终点**
固定分割比例：`1.00、0.79、0.49、0.21、0.00`，共5条水平价位线

对象权限：
1. `1.00、0.00`：整体端点，**允许拖拽**；拖动整体端点时，0.79/0.49强制回归理论比例价位，丢弃之前手动拖拽偏移。
2. `0.00、0.21`：仅绘图，不可拖拽、无下单交互。
3. `0.79、0.49`：支持鼠标上下拖拽改价位；线条右侧附带可点击下单按钮；**按钮跟随线条同步上下移动**。

区间计算
```
Range = fabs(price_1.00 − price_0.00)
止损向外偏移 = Range * 0.01
```

### 上涨模式（低点1.00 → 高点0.00）
- 0.79 / 0.49按钮：点击直接下发 **ORDER_LIMIT 限价买单**
- 止损SL：取**点击下单瞬间1.00起点价格**：`SL = price_1.00 − Range * 0.01`
- 最大亏损：账户 **Balance余额的1%**，反算手数
- 止盈TP：入场价与止损的价格距离 ×2，严格盈亏比2:1，随同挂单一并提交

### 下跌模式（高点1.00 → 低点0.00）
- 0.79 / 0.49按钮：点击直接下发 **ORDER_LIMIT 限价卖单**
- 止损SL：取**点击下单瞬间1.00起点价格**：`SL = price_1.00 + Range * 0.01`
- 最大亏损：账户 **Balance余额的1%**，反算手数
- 止盈TP：入场价与止损的价格距离 ×2，严格盈亏比2:1，随同挂单一并提交

## 手数计算规则
1. 最大允许亏损金额 = `Balance * 0.01`
2. 根据入场价‑止损的价格距离反算理论手数
3. 手数截断逻辑：直接舍弃第3位小数，保留2位，**不四舍五入**
    - 例：0.023 → 0.02；0.027 → 0.02
4. 截断后手数 ＜ 品种最小手数：弹窗提示，拒绝挂单。
5. 区间极小导致手数异常巨大：**不设置硬上限，交由人工把关**。

## 线条/按钮文字显示
> 0.79、0.49线条标记文字格式：
`0.79 BUY LIMIT(0.23)` / `0.49 BUY LIMIT(0.12)`
下跌切换为：
`0.79 SELL LIMIT(0.18)` / `0.49 SELL LIMIT(0.09)`
括号内为**当前实时计算出的手数**；仅展示手数，SL、TP不在图表显示。

## 挂单校验 & 全部拦截规则（任意一条不满足，弹窗、拒绝下单，不发订单）
1. 上涨：入场价＞0.00高点 → 拒绝
2. 下跌：入场价＜0.00低点 → 拒绝
3. 平台订单规则校验：买单SL必须低于入场价；卖单SL必须高于入场价；TP也要符合MT5订单价格约束，不合规直接弹窗拒绝
4. 手数截断后小于品种最小手数 → 拒绝

订单参数：
- 订单类型：`ORDER_LIMIT`
- 无过期时间
- 点击按钮**直接下发，无二次确认弹窗**

## 拖拽与状态行为
1. 拖拽整体端点(1.00/0.00)：0.79/0.49回归比例价位；标签上手数实时刷新预览；**不改动服务器已存在的挂单**
2. 单独拖拽0.79/0.49分割线：线条、按钮移动，标签手数实时刷新预览；**不改动服务器已存在的挂单**
3. 所有拖拽只影响**未来新点击的挂单**；历史挂单完全不变。
4. 用户手动删除EA绘制的斐波那契图形：服务器Limit挂单保留，人工自行管理。
5. EA从图表移除：图表绘图、按钮全部清除；服务器挂单保留不变。

## EA初始化流程
EA附加到图表，生成一套斐波那契绘图对象；**由用户手动拖拽1.00起点、0.00终点定义高低区间**，之后可再拖拽0.79、0.49调整入场位置。
